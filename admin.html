Primeira configuração

  1. Crie seu usuário no Supabase Authentication.
  2. Rode o arquivo supabase-schema.sql no SQL Editor.
  3. Preencha config.js com URL e chave pública.
  4. Publique no Cloudflare Pages.

Nunca coloque FAL_KEY, service_role key ou outras chaves secretas no navegador.
